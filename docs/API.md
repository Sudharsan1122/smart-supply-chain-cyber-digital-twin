# API Reference — Smart Supply Chain Cyber Digital Twin

## Overview

The Smart Supply Chain Cyber Digital Twin exposes an API-first interface powered by **FastAPI**.

- **Base URL**: `http://localhost:8000/api`
- **Interactive Swagger Documentation**: `http://localhost:8000/docs`
- **ReDoc Documentation**: `http://localhost:8000/redoc`
- **OpenAPI JSON Specification**: `http://localhost:8000/openapi.json`

---

## 1. Health & Readiness

| Method | Path | Purpose |
| :--- | :--- | :--- |
| `GET` | `/api/health` | Basic application liveness check, version, and timestamp. |
| `GET` | `/api/ready` | Deep readiness probe verifying database, MQTT broker, and twin graph state. |

---

## 2. Ingestion (Telemetry & Security Events)

| Method | Path | Purpose |
| :--- | :--- | :--- |
| `POST` | `/api/telemetry` | Ingest a single raw sensor or gateway telemetry metric. |
| `POST` | `/api/telemetry/batch` | Ingest an array of telemetry data points in a single transaction. |
| `GET` | `/api/telemetry/latest/{asset_id}` | Retrieve latest reported telemetry readings for an asset. |
| `POST` | `/api/events` | Ingest a security event (failed logins, privilege escalation, alerts). |
| `POST` | `/api/events/batch` | Batch ingest multiple security events. |
| `GET` | `/api/events/recent` | List recent security events across all assets. |

---

## 3. Digital Twin & Graph

| Method | Path | Purpose |
| :--- | :--- | :--- |
| `GET` | `/api/twin/summary` | Return graph metrics (node count, edge count, density, DAG status, roots, leaves). |
| `GET` | `/api/twin/graph` | Export complete NetworkX topology graph (nodes and adjacency list). |
| `GET` | `/api/twin/state/{asset_id}` | Get current digital twin state and health status for an asset. |
| `GET` | `/api/twin/states` | Retrieve real-time states of all 32 tracked supply chain assets. |
| `POST` | `/api/twin/reload` | Force synchronized reload of the digital twin graph from the database. |

---

## 4. Assets

| Method | Path | Purpose |
| :--- | :--- | :--- |
| `GET` | `/api/assets` | List all registered supply chain assets (gateways, warehouses, sensors, trucks). |
| `GET` | `/api/assets/{asset_id}` | Get detailed metadata, specifications, and parent-child hierarchy for an asset. |
| `POST` | `/api/assets` | Register a new asset in the supply chain catalog. |
| `PUT` | `/api/assets/{asset_id}` | Update existing asset configuration and metadata. |
| `DELETE`| `/api/assets/{asset_id}` | Remove an asset from the digital twin topology. |
